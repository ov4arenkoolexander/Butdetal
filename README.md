# BUTDETAL 2.0.8

Український Android-довідник з будівництва.

## Підключення вихідного коду

1. Завантажте архів `BUTDETAL-2.0.8-SUPABASE-SYNC-SOURCE.zip` з цього чату.
2. У корені цього репозиторію натисніть **Add file → Upload files**.
3. Завантажте архів як файл `source.zip` і натисніть **Commit changes**.
4. GitHub Actions розпакує проєкт, перевірить файли та збере debug APK.
5. APK буде доступний у вкладці **Actions → Build BUTDETAL APK → Artifacts**.

Архів містить вихідний Android-проєкт, OCR-моделі, резервне копіювання та інтеграцію Supabase. Статична перевірка архіву пройдена; компіляція Gradle і робота застосунку на пристрої ще потребують перевірки.

## Безпека Supabase

У застосунку використовуйте лише publishable/anon ключ. Ніколи не додавайте service_role або інші секретні ключі до Android-коду чи репозиторію.
