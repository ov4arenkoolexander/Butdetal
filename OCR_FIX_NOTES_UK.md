# BUTDETAL 2.0.6 — технічні зміни OCR та AndroidStorage

- Додані мовні дані Tesseract `ukr`, `rus`, `eng` у `app/src/main/assets/tessdata/`.
- Перед запуском OCR мовні дані копіюються у внутрішню папку застосунку.
- Додані методи JavaScript-моста `recognizeImage` та `recognizePdf`; PDF обробляється посторінково через Android PdfRenderer (до 40 сторінок за один запуск).
- Додані відсутні методи мосту `getCredential`, `saveCredential`, `clearCredential`, `saveDocument`.
- Пароль для функції «запам’ятати пароль» шифрується ключем Android Keystore (AES-GCM), а не зберігається відкритим текстом.
- Експорт XLSX зберігається у внутрішній папці застосунку `Documents/BUTDETAL_Експорт`.
- Додано локальний `xlsx.full.min.js`, який потрібен для імпорту/експорту Excel.

## Важливо про перевірку

Це підготовлений вихідний проєкт, а не підтверджений APK. У середовищі підготовки немає встановленого Gradle/Android SDK, тому компіляція та запуск на телефоні не виконані. Перед розповсюдженням потрібно зібрати APK через Android Studio або GitHub Actions і перевірити OCR на реальному PDF та фото, імпорт/експорт XLSX, архів фото/креслень і авторизацію Supabase. Адреса та ключ Supabase мають бути налаштовані власником проєкту; у наданому APK URL був шаблонним.
